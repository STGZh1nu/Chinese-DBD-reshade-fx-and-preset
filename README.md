# DBD Vision

**《黎明杀机》画质滤镜** · 去距离雾 + 三色独立增强 + 高光治理

ReShade本质是后期处理着色器，能够改善两大问题：

- 远处一片雾看不清，近处又太过饱和。
- 某些地图狗屎（过曝、色调过重）

> 作者：**屠皇快雪** (Snow the Great) · 许可：MIT


## 安装

### 1. 装 ReShade 本体

去 [reshade.me](https://reshade.me) 下载，安装时选游戏 `DeadByDaylight-Win64-Shipping.exe`，
渲染 API 选 **DirectX 11**，组件勾上标准效果包。

### 2. 放文件

```
<游戏目录>\DeadByDaylight\Binaries\Win64\
├── DeadByDaylight-Win64-Shipping.exe
├── dxgi.dll                          ← ReShade 本体
├── reshade-shaders\
│   └── Shaders\
│       └── DBD_Vision.fx             ← 放这里
└── 01_Universal.ini                  ← 预设放这一级（exe 同级）
   02_Eyrie_of_Crows.ini
   03_Toba_Landing.ini
   04_Garden_of_Joy.ini
```

### 3. 生效

**重启游戏**，按 `Home` 打开 ReShade 面板，顶部预设下拉框选一个。

> ReShade 只在游戏启动时扫描着色器目录，装完必须重启。

## 四份预设

| 文件 | 地图 | 特点 |
|---|---|---|
| `01_Universal` | 通用 | 低饱和 + 高锐化，画面偏冷峻清晰 |
| `02_Eyrie_of_Crows` | 乌鸦巢穴 | 高光压缩拉满，压过曝 |
| `03_Toba_Landing` | 多巴着陆点 | 紫色重压，治紫粉偏色 |
| `04_Garden_of_Joy` | 极乐园 | 保留暖秋色调，雾处理更轻 |

每份都只启用 `DBD 完整` technique。

## 参数怎么调

### 全局层

| 参数 | 作用 |
|---|---|---|
| **曝光补偿** | 整体提高亮度 |
| **高光压缩** | 把最亮的地方优化掉 |
| **暗部提亮** | 整体掺白色 |
| **全局饱和度** | 让色彩更鲜艳 |
| **对比度** | 让黑色更明显 |

### 去雾：说明可能不准确，请自己调试

| 参数 | 说明 |
|---|---|
| 去雾强度 | 0 = 关闭。过高会让画面发脏 |
| 大气光阈值 | 雾的颜色基准。**设成 1.0 等于完全不去雾** |
| 只处理雾区 | 1 = 只动低饱和发灰区域（推荐） |
| 取样半径 | 越大越能压大块雾，可能不好看但一定能看清 |

### 三色槽

三个独立槽，每个都有 **颜色 / 容差 / 强度 / 权重**：

- **强度 > 0** → 凸显（加饱和 + 提亮）
- **强度 < 0** → 削弱（去色 + 压暗）
- **强度 = 0** → 该槽不工作

**容差**：0.02 极精准（只抓色相几乎相同的），0.25 会连邻近色一起抓。

同一个 `.fx` 在不同地图靠预设**翻转正负号**：
比如青色在普通图增强（看划痕），在霓虹图削弱（压灯牌）。

## 设计取舍

写给后来改它的人：

1. **过饱和刺眼时优先压高光，不要先降饱和。** 降饱和会把画面压灰，而病根通常是亮部失控。
2. **色槽强度可正可负**，这是同一份代码适配多张地图的关键。
3. **最低饱和度是色槽的闸门**：设 0.4 时只有极鲜艳的像素能被抓到，画面大片区域其实没被处理。
4. **ReShade 退出会把面板状态写回当前预设**，调好记得「另存预设」。
5. 去雾用暗通道先验，带雾区掩码；霓虹压制只削饱和度 > 阈值的像素，正常物体不受影响。

## 性能

2K 分辨率下，`DBD 完整` 通常额外占用 2~3%。主要开销是去雾的 4 次采样。
